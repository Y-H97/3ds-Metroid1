# 3ds-cpp Dokumentation

Dieser Ordner enthält technische Doku zur C++-Version.

## Inhalte
- `ARCHITECTURE.md` – Überblick über Module und Verantwortlichkeiten.
- `RUNTIME_FLOW.md` – Laufzeitfluss vom Hauptmenü ins Gameplay.
- `SAVE_AND_SETTINGS.md` – Save-Slots, Fog-of-War und Settings-Persistenz.
- `COMPONENT_STRUCTURE.md` – Ordnerstruktur mit Komponenten- und Modulbeschreibung.
- `REFACTORING_ASSESSMENT.md` – Bewertung, was weiter unterteilt werden sollte.

## Einstieg
1. `ARCHITECTURE.md` lesen.
2. Danach `RUNTIME_FLOW.md` für den tatsächlichen Ablauf.
3. Für Persistenz-Themen `SAVE_AND_SETTINGS.md`.
